# Arduino Nano OLED Solder Monitor

DIY Temperaturanzeige für Lötkolben / Heizelemente.

## Hardware

- Arduino Nano ATmega328
- SSD1306 OLED I2C
- 100K NTC 3950
- 10K Widerstand

## Features

- Große Temperaturanzeige
- OLED SSD1306
- Aufheizsymbol ↑
- Lötbereit ✓
- Überhitzung ↓
- Statusanzeige
- Serial Monitor Debug

## Verdrahtung

5V -> NTC -> A0 -> 10K -> GND

OLED:
- SDA -> A4
- SCL -> A5

## Libraries

- Adafruit SSD1306
- Adafruit GFX
